# Лабораторная работа №2 — вариант 1

Перегрузка операций, методы расширения, наследование, полиморфизм (C#, .NET 8).

Выполнили: Захаров А.В., Саламов Ю.Ш., Антропов Г.С., группа АВТ-514, НГТУ.

Проект на GitHub: https://github.com/users/zaar2077-hub/projects/3

## Состав решения

| Проект | Назначение |
|---|---|
| `src/ArrayOperations` | Часть 1. Класс `IntArray` (одномерный массив) с перегруженными операциями `*`, `true`/`false`, `(int)`, `==`/`!=`, `<`/`>`; методы расширения `ContainsChar` и `RemoveNegatives` |
| `src/GoodsHierarchy` | Часть 2. Иерархия «Товар → Техника → Печатающее устройство / Сканер / Компьютер → Планшет» |
| `tests/Lab2.Tests` | Программа тестирования: 66 тестов, собственный мини-фреймворк на основе отражения |

## Запуск

```
dotnet run --project src/ArrayOperations
dotnet run --project src/GoodsHierarchy
dotnet run --project tests/Lab2.Tests
```

Программа тестирования возвращает код 0, если все тесты пройдены.
